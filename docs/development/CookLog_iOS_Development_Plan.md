# CookLog iOS 개발 계획

이 문서는 CookLog iOS MVP 개발의 이정표, 체크리스트, 인수인계 기준을 관리하는 진행 문서입니다. iOS 개발 세션은 작업 시작 전 이 문서를 읽고, 작업 종료 전 진행 상태를 업데이트합니다.

작성일: 2026-06-19
최종 업데이트: 2026-06-19

## 현재 상태 요약

- 상태: 개발 준비 단계
- iOS 프로젝트: 아직 생성 전
- 현재 로컬 Xcode: 15.2
- 권장 구현: SwiftUI + MVVM + 로컬 저장 + Mock AI 우선
- 우선 참고 문서: `docs/development/CookLog_iOS_Development_Environment.md`

## 개발 원칙

- MVP는 iOS 네이티브 앱으로 먼저 완성합니다.
- 로그인, 공유, 커뮤니티, Import 기능은 만들지 않습니다.
- 외부 API 연동보다 앱의 핵심 흐름을 먼저 동작시킵니다.
- AI, STT, TTS는 서비스 인터페이스 뒤에 숨겨 교체 가능하게 만듭니다.
- 개발 진행 중 이 문서의 체크리스트와 다음 작업 항목을 계속 갱신합니다.

## 핵심 MVP 목표

사용자는 짧은 요리 로그를 남기고, 앱은 이를 레시피 구조로 정리해 저장하며, 나중에 저장된 레시피를 단계별 오디오 가이드로 다시 들려줘야 합니다.

성공 기준:

- 사용자가 Home에서 기록을 시작할 수 있습니다.
- 사용자가 텍스트 또는 음성으로 요리 로그를 남길 수 있습니다.
- 로그가 제목, 재료, 순서, 메모를 가진 레시피로 정리됩니다.
- 정리된 레시피를 저장할 수 있습니다.
- 저장된 레시피 목록과 상세 화면을 볼 수 있습니다.
- 저장된 레시피를 단계별 오디오 플레이어로 재생할 수 있습니다.

## 열린 질문

- 실제 프로젝트 생성 시 Xcode 15.2를 그대로 사용할지, 최신 안정 Xcode로 업데이트한 뒤 시작할지 결정이 필요합니다.
- 최소 iOS 버전을 iOS 17 이상으로 확정할지, iOS 16 지원을 고려할지 결정이 필요합니다.
- 로컬 저장을 SwiftData로 바로 시작할지, 프로젝트 생성 환경에 따라 JSON 저장으로 먼저 시작할지 결정이 필요합니다.
