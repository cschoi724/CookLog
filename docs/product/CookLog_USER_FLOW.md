# CookLog USER FLOW v2

## 기록 흐름

Home
-> 요리 기록 시작
-> 10초 기록
-> STEP Preview 생성
-> 10초 기록 반복
-> AI 정리하기
-> 레시피 검토
-> 저장
-> 레시피 상세
-> 오디오 가이드

## STEP Preview 흐름

1. 사용자가 10초 기록 버튼을 누릅니다.
2. 10초 동안 음성을 녹음합니다.
3. STT 결과를 텍스트로 변환합니다.
4. 변환된 텍스트를 다음 STEP Preview로 추가합니다.
5. 사용자는 필요한 만큼 10초 기록을 반복합니다.
6. 기록이 끝나면 `AI 정리하기`를 선택합니다.
