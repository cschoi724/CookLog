# CookLog USER FLOW v2

## 첫 실행

1. 별도의 다단계 온보딩 없이 Home으로 바로 진입합니다.
2. 첫 기록, 첫 AI Review와 첫 핸즈프리에서만 해당 기능의 짧은 안내를 한 번 표시합니다.
3. 안내를 닫거나 확인한 뒤 현재 행동을 바로 계속합니다.

## 기록 흐름

Home
-> 요리 기록 시작
-> 10초 기록
-> STEP Preview 생성
-> 10초 기록 반복
-> AI 정리하기
-> 레시피 검토
-> 임시 저장 또는 레시피 저장
-> 레시피 상세
-> 오디오 가이드

## STEP Preview 흐름

1. 사용자가 처음 `10초 요리 기록 시작`을 누르면 사용 이유를 설명하고 마이크 권한을 요청합니다.
2. 권한이 있으면 10초 기록을 시작합니다.
3. 10초 동안 음성을 녹음합니다.
4. STT 결과를 텍스트로 변환합니다.
5. 변환된 텍스트를 다음 STEP Preview로 추가합니다.
6. Preview가 추가되거나 삭제될 때마다 텍스트 초안을 자동 저장합니다.
7. 사용자는 필요한 만큼 10초 기록을 반복합니다.
8. 잘못된 Preview는 왼쪽 스와이프로 삭제하고 짧은 시간 안에 되돌릴 수 있습니다.
9. Preview 순서는 녹음 시간순으로 고정합니다.
10. 기록이 끝나면 `AI 정리하기`를 선택합니다.

## 마이크 권한 거부 흐름

1. 권한을 거부해도 Home과 기존 레시피 기능을 계속 사용합니다.
2. 기록을 다시 시도하면 권한 필요 이유와 `설정으로 이동`을 표시합니다.
3. 안내를 닫으면 현재 화면에 머무릅니다.

## 오프라인 흐름

1. 지원되는 Apple 기기의 기기 내 STT로 새 10초 기록과 STEP Preview 생성을 계속합니다.
2. 음성을 기기에 대기열로 장기 보관하지 않고 원격 STT로 자동 전환하지 않습니다.
3. 기존 STEP Preview, 진행 레시피, 완료 레시피와 로컬 Audio Guide를 계속 사용합니다.
4. `AI 정리하기`를 선택하면 인터넷 연결 필요 안내를 표시하고 STEP Preview에 머무릅니다.

## STT 실패 흐름

1. 앱이 마이크, 녹음, 기기 내 STT 지원 여부와 인식 오류를 구분합니다.
2. 복구 가능한 기술 오류는 원본 음성을 임시 보관하고 같은 기기 내 adapter로 1회 자동 재처리합니다.
3. 재처리 성공 시 STEP Preview를 생성하고 원본 음성을 삭제합니다.
4. 최종 실패 시 원격 STT로 전환하지 않고 새 STEP Preview를 만들지 않습니다. 원인을 안내한 뒤 원본 음성을 삭제합니다.
5. 기존 STEP Preview와 진행 기록은 그대로 보존합니다.
6. 사용자는 `다시 기록하기`로 새 10초 기록을 시작하거나 기존 기록으로 계속 진행할 수 있습니다.

## 온라인 AI 서비스 장애 흐름

1. 인터넷 연결 문제와 CookLog·외부 AI 서비스 문제를 내부적으로 구분합니다.
2. 사용자에게 내부 코드나 업체명 대신 원인 범주와 지금 할 수 있는 행동을 표시합니다.
3. 장애가 발생한 AI 기능만 실패 처리하고 기기 내 STT 기록, 진행 기록, 완료 레시피, 로컬 검색과 Audio Guide는 계속 사용합니다.
4. 서비스가 복구돼도 실패한 AI 정리를 자동 실행하지 않습니다.
5. 사용자가 `다시 정리하기`를 명시적으로 선택합니다.
6. 첫 출시에서는 장애 복구 푸시나 자동 화면 이동을 제공하지 않습니다.

## AI Review 흐름

1. `AI 정리하기`가 STEP Preview 전체를 제목, 재료, 단계, 예상 시간과 메모로 구조화합니다.
2. AI가 처음 생성한 Review를 기본 초안으로 저장합니다.
3. 사용자는 단계별 입력 카드에서 내용을 수정·추가·삭제·재배열합니다.
4. `임시 저장`은 현재 Review를 저장하고 화면에 머문 채 토스트를 표시합니다.
5. 저장하지 않은 수정사항이 있는 상태에서 나가면 저장·폐기·계속 작성을 선택합니다.
6. `레시피 저장`은 진행 중 상태를 완료 레시피로 전환합니다.

## 최종 레시피 저장 실패 흐름

1. 최종 저장에는 제목과 조리 단계 최소 1개가 필요합니다.
2. 재료, 수량, 예상 시간과 메모가 없어도 저장할 수 있습니다.
3. 빈 재료 행은 무시하고 재료명만 있는 행은 수량 없이 저장합니다.
4. 수량만 있고 재료명이 없는 행은 해당 재료명 필드에 입력 안내를 표시합니다.
5. 빈 조리 단계 카드는 제외하고 내용이 있는 단계만 순서대로 다시 번호를 부여합니다.
6. 내용이 있는 단계가 하나도 없을 때만 조리 단계 입력 안내와 함께 저장을 막습니다.
7. 저장이 실패하면 완료 상태로 전환하지 않고 현재 AI Review와 편집값을 유지합니다.
8. 입력 조건 문제는 해당 필드에, 로컬 저장소 문제는 화면 공통 오류로 원인을 표시합니다.
9. 사용자는 `다시 저장`, 계속 수정 또는 임시 저장을 선택할 수 있습니다.
10. 다시 저장해도 같은 진행 기록을 사용해 완료 레시피를 중복 생성하지 않습니다.
11. 앱이 종료되면 마지막으로 성공한 임시 저장 상태로 복구합니다.

## AI 정리 실패 흐름

1. AI 정리 요청 식별자와 처리 중 상태를 저장하고 중복 실행을 막습니다.
2. 처리에 사용한 STEP Preview는 완료 전까지 추가·삭제할 수 없게 잠급니다.
3. Home에서 해당 카드를 `AI 정리 중`으로 표시하고 다른 레시피 사용은 허용합니다.
4. 시작 즉시 진행 상태를 표시하고 10초가 지나면 장기 처리 안내를 표시합니다.
5. 장기 처리 안내는 다른 화면을 이용해도 정리가 계속됨을 알립니다.
6. 첫 출시에서는 AI 정리 취소 기능을 제공하지 않습니다.
7. 앱이 백그라운드로 이동해도 서버 요청은 계속 처리합니다.
8. 앱 복귀 또는 재실행 시 같은 요청 결과를 확인합니다.
9. 같은 요청으로 AI Review를 한 번만 생성합니다.
10. 다른 화면을 보는 동안 완료되면 앱 내부 배너와 Home의 `검토 준비됨` 상태로 알립니다.
11. 배너를 누르면 AI Review로 이동하지만 자동 화면 전환은 하지 않습니다.
12. 첫 출시에서는 로컬 알림과 원격 푸시를 사용하지 않습니다.
13. 성공하면 AI Review로 전환하고 실패하면 STEP Preview 잠금을 해제합니다.
14. 오프라인에서도 `AI 정리하기` 버튼을 표시합니다.
15. 오프라인에서 누르면 인터넷 연결 필요 안내를 표시하고 STEP Preview에 머무릅니다.
16. 빈 입력, 네트워크, 시간 초과, 서비스 장애, 응답 형식과 이용량 상태를 구분합니다.
17. 실패 원인과 사용자가 할 수 있는 행동을 표시합니다.
18. STEP Preview는 항상 보존합니다.
19. 연결 복구나 실패 후 자동 재처리하지 않고 사용자가 `다시 정리하기` 또는 `기록으로 돌아가기`를 선택합니다.

## 지원 정보 흐름

1. 사용자는 `앱 정보`에서 이메일 문의, 개인정보처리방침, 이용약관과 데이터 보관 안내를 확인합니다.
2. 문의 메일에 음성, STT 본문, 레시피 내용과 검색어를 자동 첨부하지 않습니다.
3. 사용자가 직접 선택한 경우에만 앱 버전과 비콘텐츠 진단 정보를 문의에 포함합니다.

## 진행 기록 이어가기

1. Home은 진행 기록과 완료 레시피를 하나의 목록에 마지막 활동 시간순 최대 3개까지 표시합니다.
2. STEP Preview 카드는 마지막 기록 상태로 이동합니다.
3. AI Review 카드는 마지막 임시 저장 상태로 이동합니다.
4. 완료 레시피 카드는 Recipe Detail로 이동합니다.
5. AI 정리 완료, STEP 변경과 AI Review 임시 저장을 최근 활동으로 반영합니다.
6. 나머지는 `전체 보기`에서 확인합니다.
7. 여러 진행 레시피를 보관할 수 있지만 한 번에 하나만 편집합니다.

## 레시피 검색

1. Home의 `전체 보기`에서 검색어를 입력합니다.
2. 기기 내부에서 AI Review 진행 기록과 완료 레시피의 제목·재료명이 일치하는 결과를 즉시 표시합니다.
3. 아직 제목과 재료가 없는 STEP Preview 진행 기록은 검색 대상에서 제외합니다.
4. 검색어와 레시피 내용은 서버나 AI로 전송하지 않습니다.
5. 기본 목록은 마지막 활동 시간순으로 표시합니다.
6. 검색 결과는 제목 일치, 재료명 일치 순으로 우선하고 같은 조건에서는 최근 활동순으로 표시합니다.
7. 결과가 없으면 빈 검색 결과를 안내하고 검색어를 지울 수 있게 합니다.

## 다시 요리 흐름

Home
-> 저장된 레시피
-> 레시피 상세
-> 오디오 가이드 시작
-> 재생 또는 핸즈프리 시작
-> 현재 단계 듣기
-> 다음·이전·일시정지·다시 듣기
-> 마지막 단계 유지
-> 가이드 종료

## 핸즈프리 권한 흐름

1. 사용자가 처음 `핸즈프리 시작`을 선택하면 사용 이유를 설명합니다.
2. 필요한 마이크 또는 음성인식 시스템 권한을 요청합니다.
3. 권한을 허용하면 핸즈프리를 활성화합니다.
4. 거부하면 핸즈프리만 비활성화하고 버튼 기반 Audio Guide를 유지합니다.
5. 다시 시도하면 권한 안내와 `설정으로 이동`을 제공하며 시스템 권한창을 반복 호출하지 않습니다.

## 완료 레시피 수정·삭제

- Recipe Detail의 `레시피 수정`은 AI Review와 같은 폼을 사용해 기존 레시피를 업데이트합니다.
- 수정은 AI를 다시 호출하지 않고 이전 버전을 남기지 않습니다.
- 완료 레시피 삭제는 Recipe Detail에서 확인창을 거쳐 영구 삭제하며 복구하지 않습니다.
