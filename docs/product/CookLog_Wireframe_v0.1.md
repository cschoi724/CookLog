# 와이어프레임

## 화면 목록

MVP에 필요한 화면은 다음 5개로 정의한다.

1. 홈 / 레시피 저장소
2. 요리 로그 입력
3. AI 정리 결과 미리보기
4. 레시피 상세
5. 오디오 플레이어

---

## 홈 / 레시피 저장소

### 목적

저장된 개인 레시피를 찾고, 새 요리 기록을 시작한다.

### 구성

```text
┌──────────────────────────────┐
│ CookLog                      │
│ 나만의 레시피 저장소          │
├──────────────────────────────┤
│ [검색어 입력]                 │
├──────────────────────────────┤
│ + 요리 기록하기               │
├──────────────────────────────┤
│ 최근 레시피                   │
│                              │
│ ┌──────────────────────────┐ │
│ │ 버터 굴소스 삼겹살 볶음   │ │
│ │ 삼겹살, 양파, 굴소스      │ │
│ │ 2026.06.19               │ │
│ └──────────────────────────┘ │
│                              │
│ ┌──────────────────────────┐ │
│ │ 고추장 계란 볶음밥        │ │
│ │ 밥, 계란, 고추장          │ │
│ │ 2026.06.15               │ │
│ └──────────────────────────┘ │
└──────────────────────────────┘
```

### 빈 상태

```text
┌──────────────────────────────┐
│ CookLog                      │
├──────────────────────────────┤
│ 아직 저장된 레시피가 없어요.  │
│ 오늘 만든 요리를 짧게 남겨보세요. │
│                              │
│ [첫 요리 기록하기]            │
└──────────────────────────────┘
```

## 요리 로그 입력

### 목적

사용자가 부담 없이 자유로운 형태로 요리 기록을 남긴다.

### 구성

```text
┌──────────────────────────────┐
│ ← 요리 기록하기              │
├──────────────────────────────┤
│ 오늘 만든 요리를 적어주세요   │
│                              │
│ ┌──────────────────────────┐ │
│ │ 삼겹살 넣음               │ │
│ │ 양파 반개                 │ │
│ │ 굴소스 두바퀴             │ │
│ │ 버터 조금                 │ │
│ │ 다음엔 후추 추가          │ │
│ └──────────────────────────┘ │
│                              │
│ [AI로 레시피 만들기]          │
└──────────────────────────────┘
```

### 입력 가이드

화면 안에 긴 설명을 넣지 않고 placeholder 중심으로 유도한다.

예시:

```text
넣은 재료, 양념, 순서, 다음에 바꿀 점을 편하게 적어주세요.
```

## AI 정리 결과 미리보기

### 목적

AI가 만든 레시피를 저장 전 사용자가 검토하고 수정한다.

### 구성

```text
┌──────────────────────────────┐
│ ← 레시피 확인                │
├──────────────────────────────┤
│ 제목                          │
│ [버터 굴소스 삼겹살 볶음]     │
├──────────────────────────────┤
│ 재료                          │
│ - 삼겹살                      │
│ - 양파 1/2개                  │
│ - 굴소스                      │
│ - 버터                        │
├──────────────────────────────┤
│ 조리 순서                     │
│ 1. 팬에 삼겹살을 굽는다.      │
│ 2. 양파를 넣고 함께 볶는다.   │
│ 3. 굴소스를 넣어 간한다.      │
│ 4. 버터를 넣고 마무리한다.    │
├──────────────────────────────┤
│ 메모                          │
│ 다음에는 후추를 추가해보기    │
│                              │
│ [저장]                        │
└──────────────────────────────┘
```

### 수정 가능 항목

- 제목
- 재료
- 조리 순서
- 메모

## 레시피 상세

### 목적

저장된 레시피를 읽고 오디오 가이드를 시작한다.

### 구성

```text
┌──────────────────────────────┐
│ ← 버터 굴소스 삼겹살 볶음     │
├──────────────────────────────┤
│ [오디오로 요리하기]           │
├──────────────────────────────┤
│ 재료                          │
│ - 삼겹살                      │
│ - 양파 1/2개                  │
│ - 굴소스                      │
│ - 버터                        │
├──────────────────────────────┤
│ 조리 순서                     │
│ 1. 팬에 삼겹살을 굽는다.      │
│ 2. 양파를 넣고 함께 볶는다.   │
│ 3. 굴소스를 넣어 간한다.      │
│ 4. 버터를 넣고 마무리한다.    │
├──────────────────────────────┤
│ 메모                          │
│ 다음에는 후추를 추가해보기    │
└──────────────────────────────┘
```

## 오디오 플레이어

### 목적

사용자가 화면을 오래 보지 않고 요리를 따라 할 수 있게 한다.

### 구성

```text
┌──────────────────────────────┐
│ ← 오디오 가이드              │
├──────────────────────────────┤
│ 버터 굴소스 삼겹살 볶음       │
│                              │
│ 2 / 4 단계                   │
│                              │
│ 양파를 넣고 함께 볶으세요.    │
│                              │
│ [다시 듣기]                   │
│                              │
│ [이전]   [재생/정지]   [다음] │
└──────────────────────────────┘
```

### 완료 상태

```text
┌──────────────────────────────┐
│ 요리 완료                    │
├──────────────────────────────┤
│ 모든 단계를 들었어요.         │
│                              │
│ [레시피로 돌아가기]           │
└──────────────────────────────┘
```
