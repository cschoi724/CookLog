# MVP 상세 명세

## MVP 목표

CookLog MVP는 다음 가설을 검증한다.

> 사용자는 정형화된 레시피 입력보다 짧은 자유 기록을 더 쉽게 남기며, 저장된 개인 레시피를 오디오로 다시 따라 하는 것에 가치를 느낀다.

---

### 포함 기능

- 레시피 목록 조회

### 제외 기능

- 좋아요

## 기능 상세

## 기능 1. 요리 로그 입력

### 설명

사용자는 요리 중 또는 요리 후 자유 텍스트로 기록을 남긴다.

### 입력

- 자유 텍스트

### 필수 조건

- 최소 10자 이상 입력
- 공백만 입력할 수 없음

### 주요 액션

- 뒤로가기
- 로그 입력
- AI 정리 요청

### 오류 상태

- 입력값 없음
- 입력값이 너무 짧음

### 성공 조건

- 유효한 로그가 AI 정리 요청으로 전달된다.

---

## 기능 2. AI 레시피 정리

### 설명

사용자의 자유 기록을 구조화된 레시피로 변환한다.

### 입력

- rawLog

### 출력

- title
- ingredients
- steps
- memo

### 기본 변환 규칙

- 제목은 요리의 핵심 재료와 조리 특징을 반영한다.
- 재료는 사용자가 언급한 항목을 우선한다.
- 양이 불명확하면 `적당량` 또는 빈 값으로 둔다.
- 조리 순서는 사용자의 기록 순서를 최대한 유지한다.
- 개선점, 다음에 바꿀 점은 메모로 분리한다.

### 오류 상태

- AI 요청 실패
- 응답 형식 오류
- 네트워크 오류

### 성공 조건

- 사용자가 저장 가능한 레시피 초안을 확인할 수 있다.

---

## 기능 3. 레시피 미리보기 및 수정

### 설명

AI가 생성한 레시피를 저장 전 수정할 수 있다.

### 수정 가능 항목

- 제목
- 재료명
- 재료 분량
- 조리 순서
- 메모

### 필수 조건

- 제목은 비어 있을 수 없음
- 조리 순서는 최소 1개 이상 필요

### 주요 액션

- 항목 수정
- 저장
- 뒤로가기

### 성공 조건

- 수정된 데이터가 저장소에 저장된다.

---

## 기능 4. 레시피 저장소

### 설명

사용자의 개인 레시피를 목록으로 보여준다.

### 목록 항목 표시 정보

- 제목
- 대표 재료 2~3개
- 생성일 또는 수정일

### 정렬

- 최신 수정순을 기본값으로 한다.

### 빈 상태

- 저장된 레시피가 없으면 첫 기록 버튼을 표시한다.

### 성공 조건

- 사용자가 저장된 레시피를 빠르게 찾고 상세로 이동할 수 있다.

---

## 기능 5. 검색

### 설명

저장된 레시피를 키워드로 검색한다.

### 검색 대상

- 제목
- 재료명
- 메모

### 검색 방식

- 부분 일치
- 대소문자 구분 없음

### 빈 결과

```text
검색 결과가 없어요.
다른 재료나 요리 이름으로 찾아보세요.
```

---

## 기능 6. 레시피 상세

### 설명

저장된 레시피의 전체 내용을 보여준다.

### 표시 항목

- 제목
- 재료
- 조리 순서
- 메모
- 오디오 가이드 시작 버튼

### 주요 액션

- 오디오로 요리하기
- 뒤로가기

### 성공 조건

- 사용자가 레시피 정보를 확인하고 오디오 플레이어로 이동할 수 있다.

---

## 기능 7. 오디오 플레이어

### 설명

레시피 조리 순서를 단계별 오디오로 재생한다.

### 표시 항목

- 레시피 제목
- 현재 단계 번호
- 전체 단계 수
- 현재 단계 문장
- 재생 상태

### 제어

- 재생
- 정지
- 이전 단계
- 다음 단계
- 다시 듣기

### 재생 규칙

- 플레이어 진입 시 1단계부터 시작한다.
- `다음`을 누르면 다음 단계 문장을 재생한다.
- `이전`을 누르면 이전 단계 문장을 재생한다.
- `다시 듣기`를 누르면 현재 단계를 처음부터 재생한다.
- 마지막 단계에서 `다음`을 누르면 완료 상태를 표시한다.

### MVP 구현 기준

초기 버전에서는 실제 음성 파일 저장 없이 디바이스 TTS 또는 브라우저 Speech API를 사용할 수 있다.

## AI 프롬프트 초안

```text
사용자의 요리 기록을 개인 레시피로 정리해줘.

조건:
- 사용자가 쓴 내용을 과하게 상상하지 말 것
- 언급된 재료와 조리 흐름을 우선할 것
- 양이 명확하지 않으면 amount를 비워둘 것
- 다음에 바꿀 점이나 감상은 memo로 분리할 것
- 조리 단계는 짧고 음성으로 듣기 좋은 문장으로 만들 것

출력 형식:
{
  "title": "",
  "ingredients": [
    { "name": "", "amount": "" }
  ],
  "steps": [
    { "description": "", "audioText": "" }
  ],
  "memo": ""
}

사용자 기록:
{{rawLog}}
```

## MVP 성공 지표

### 사용성 지표

- 첫 레시피 저장 완료율
- 로그 입력 시작 후 AI 정리 완료율
- AI 정리 결과 저장률
- 저장된 레시피 재조회율
- 오디오 플레이어 실행률

### 정성 지표

- 사용자가 기록 입력을 부담스럽지 않게 느끼는가
- AI가 만든 레시피를 수정 없이 저장할 만큼 쓸만한가
- 오디오 플레이어가 실제 요리 중 도움이 되는가

---

## 구현 메모

### 데이터 저장

MVP 초기 검증 단계에서는 로컬 저장소를 우선 사용할 수 있다.

- 웹: localStorage 또는 IndexedDB
- 모바일: 로컬 DB 또는 파일 기반 저장

### AI 연동

초기에는 로그 입력 후 수동 요청 방식으로 충분하다.

- 자동 생성보다 사용자가 명확히 `AI로 레시피 만들기`를 누르는 흐름이 적합하다.
- AI 실패 시 사용자가 원본 로그를 잃지 않도록 입력값을 유지해야 한다.

### 오디오

초기 MVP에서는 녹음 파일 생성보다 TTS 재생이 적합하다.

- 단계별 짧은 문장
- 재생, 정지, 이전, 다음, 다시 듣기
- 화면을 보지 않아도 이해 가능한 문장
