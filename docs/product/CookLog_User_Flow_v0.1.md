# 사용자 플로우(User Flow)

## 핵심 사용자 목표

사용자는 요리 중 또는 요리 후 짧은 기록을 남기고, CookLog는 이를 AI로 정리해 개인 레시피로 저장한다. 사용자는 나중에 저장된 레시피를 선택해 오디오 가이드로 다시 요리할 수 있다.

---

## 주요 플로우 요약

### Flow A. 첫 진입

앱 실행

→ 레시피 저장소 홈 진입

→ 저장된 레시피가 없으면 빈 상태 화면 노출

→ `요리 기록하기` 선택

→ 로그 입력 화면으로 이동

---

### Flow B. 요리 로그 기록

홈

→ `요리 기록하기`

→ 자유 텍스트로 요리 로그 입력

→ `AI로 레시피 만들기`

→ AI 정리 진행

→ 레시피 미리보기 화면

→ 사용자가 제목, 재료, 순서, 메모 확인 및 수정

→ `저장`

→ 레시피 상세 화면으로 이동

---

### Flow C. 저장된 레시피 다시 보기

홈

→ 레시피 목록 확인

→ 검색 또는 목록 스크롤

→ 레시피 선택

→ 레시피 상세 화면 진입

→ 재료, 조리 순서, 메모 확인

---

### Flow D. 오디오 가이드로 요리하기

레시피 상세

→ `오디오로 요리하기`

→ 오디오 플레이어 화면 진입

→ 현재 단계 음성 재생

→ 사용자는 다음 동작 중 하나 수행

- 재생
- 정지
- 이전 단계
- 다음 단계
- 다시 듣기

→ 마지막 단계 완료

→ 요리 완료 화면 또는 레시피 상세로 복귀

---

### Flow E. 레시피 검색

홈

→ 검색어 입력

→ 제목, 재료, 메모 기준으로 필터링

→ 결과 목록 표시

→ 레시피 선택

→ 상세 화면 진입

---

## 예외 플로우

### AI 정리 실패

로그 입력

→ AI 정리 요청

→ 실패

→ 오류 메시지 표시

→ 사용자는 다시 시도 또는 직접 작성 선택

### 로그가 너무 짧은 경우

로그 입력

→ `AI로 레시피 만들기`

→ 최소 입력 조건 미달

→ 추가 기록 안내

예시 문구:

> 어떤 재료를 넣었는지 한두 줄만 더 적어주세요.

### 저장된 레시피가 없는 경우

홈

→ 빈 상태 화면

→ `첫 요리 기록하기` 버튼 표시
