# CookLog MVP Scope v2

이 문서는 PRD v2 기준의 MVP 포함/제외 범위입니다.

범위 해석:

- `Core MVP`: Mock을 포함해 핵심 기록·저장·재사용 흐름을 검증하는 기능 기준입니다.
- `첫 App Store 공개 출시`: 실제 Apple 기기 내 STT·온라인 AI, 로컬 TTS, 핸즈프리, 개인정보·장애 대응과 최소 출시 검증까지 포함한 배포 기준입니다.
- 수익화, Android와 후속 확장은 첫 공개 출시 차단 조건이 아닙니다.

## Include

- Home
- 10초 음성 기록
- STT
- STEP Preview 생성
- 10초 기록 반복
- AI 정리
- 레시피 검토
- STEP Preview 자동 저장과 AI Review 수동 임시 저장
- 여러 진행 레시피 이어가기
- 레시피 저장
- 레시피 조회
- 기기 내부 로컬 레시피 저장
- 전체 보기의 제목·재료명 로컬 검색
- 완료 레시피 수정
- 버튼 기반 오디오 가이드

- 로그인
- 회원가입
- 공유
- 커뮤니티
- Import 기능
- OCR

- 서버 동기화
- CookLog 계정 기반 백업·복구
- 레시피 내보내기
- 조기 녹음 종료
- 녹음 시간 연장
- 녹음 일시중지·재개
- 레시피 버전 기록
- 삭제 레시피 복구
- 수익화와 Pro 구독 활성화
- Android 앱

## 구현상 중요한 구분

- STEP Preview는 STT 결과를 기반으로 즉시 생성합니다.
- STEP Preview 단계에서는 실제 AI 레시피 구조화를 수행하지 않습니다.
- AI는 사용자가 `AI 정리하기`를 선택한 시점에만 호출합니다.
- 사용자는 레시피를 직접 작성하지 않고 음성으로만 요리 과정을 기록합니다.
- 10초 녹음은 고정 시간으로 자동 종료하며 조기 종료는 향후 확장으로 둡니다.
- 음성은 STT 처리와 복구 가능한 오류의 1회 자동 재처리에만 임시 사용하고 이후 삭제합니다.
- 첫 출시 기본 경로에서는 앱 내부 임시 음성만 만들고 Backend 음성 사본을 생성하지 않습니다. 앱 임시 음성은 처리가 끝나면 즉시 삭제하고 비정상 잔존 방지 TTL을 최대 1시간으로 제한합니다.
- 향후 원격 STT adapter를 별도 승인으로 활성화할 때만 Backend 임시 음성에 즉시 삭제·최대 1시간 TTL을 적용합니다.
- 첫 출시는 지원되는 Apple 기기의 기기 내 STT를 기본으로 사용합니다.
- 유료 원격 STT는 공통 인터페이스 뒤의 교체형 adapter로 유지하되 기본 비활성화하고 자동 fallback하지 않습니다.
- 같은 기기 내 adapter의 복구 가능한 기술 오류만 최대 1회 재처리합니다.
- STEP Preview 텍스트는 추가·삭제 시마다 자동 저장합니다.
- AI Review 수정사항은 사용자가 `임시 저장`을 눌렀을 때 저장합니다.
- 조리 순서는 단계별 독립 항목으로 저장·수정·재배열합니다.
- AI 정리 실패 시 자동 재처리하지 않고 사용자가 `다시 정리하기`를 선택합니다.
- 최종 레시피 저장은 제목과 조리 단계 최소 1개만 필수로 하며 재료·수량·예상 시간·메모는 선택 입력입니다.
- 지원 환경에서는 새 음성 기록, 기존 텍스트 기록과 로컬 Audio Guide를 오프라인에서 사용할 수 있지만 AI 정리에는 인터넷 연결이 필요합니다.
- 마이크·녹음·기기 내 STT, 인터넷 연결, CookLog AI 서비스 장애를 구분하고 사용자에게 내부 코드나 업체명 대신 현재 가능한 행동을 안내합니다.
- STT 최종 실패 시 새 STEP을 만들지 않고 기존 기록을 보존한 채 `다시 기록하기`를 제공합니다.
- AI 정리 실패 시 기존 STEP을 보존하고 자동 재실행 없이 `다시 정리하기`를 제공합니다.
- 첫 출시는 레시피와 진행 기록을 기기 내부에만 저장하며 CookLog 자체 클라우드 백업·복구를 제공하지 않습니다.
- 일반 앱 업데이트에는 기존 로컬 데이터를 유지하지만 앱 삭제, 기기 초기화·분실 시 데이터가 유실될 수 있습니다.
- STT·AI 입력과 결과는 운영 DB·분석·오류 로그에 영구 저장하지 않습니다.
- AI 결과 복구용 콘텐츠 캐시는 앱 수신 확인 즉시, 확인되지 않아도 최대 24시간 뒤 삭제합니다.
- 요청 결과·지연시간·사용량처럼 사용자 콘텐츠가 없는 운영 메타데이터만 최대 30일 보관합니다.

## 첫 App Store 공개 출시 추가 필수

- 사용자가 `핸즈프리 시작`을 눌러 활성화하는 Audio Guide 음성 명령
- `다음`, `이전`, `멈춰`, `계속`, `다시 들려줘`, `재료 알려줘`, `핸즈프리 종료`
- 음성 명령 실패 시 모든 행동을 버튼으로 이어가는 fallback
- `앱 정보`의 이메일 문의, 개인정보처리방침, 이용약관과 데이터 보관 안내
- 첫 출시에서는 실시간 채팅, 24시간 고객지원과 별도 서비스 상태 페이지를 제공하지 않습니다.
