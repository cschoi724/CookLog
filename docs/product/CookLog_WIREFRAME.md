# CookLog WIREFRAME v2

## 1. Home

- 첫 실행 시 별도 온보딩 없이 바로 표시
- 요리 기록 시작
- 최근 레시피
- 저장된 레시피 목록 진입
- 진행 단계별 카드 상태
  - `기록 중 · STEP n개`
  - `AI 정리 중 · STEP n개`
  - `검토 필요 · AI 제목 · 주요 재료`
  - 완료 레시피 기본 카드
- 완료 카드: 제목, 주요 재료 최대 3개, 예상 시간, 단계 수
- 완료 카드에는 별도 완료 배지 없음
- 카드를 누르면 STEP Preview, AI Review 또는 Recipe Detail의 현재 단계로 이동
- 여러 진행 레시피를 완료 레시피와 같은 목록에 마지막 활동 시간순 최대 3개 표시
- 나머지는 전체 보기에서 확인
- 진행 기록 카드 `⋯` 메뉴에서 전체 삭제
- 첫 기록 시 마이크 사용 이유 안내
- 마이크 권한 거부 시 설정으로 이동
- 첫 기록 맥락형 안내
- 온라인 기능 장애 상태와 다시 시도 행동
- 앱 정보 진입

### 앱 정보

- 이메일 문의하기
- 개인정보처리방침
- 이용약관
- 데이터 보관 안내
- 문의에 사용자 콘텐츠를 자동 첨부하지 않음

### 전체 보기

- 제목·재료명 로컬 검색 필드
- 입력 중 즉시 갱신되는 결과 목록
- 검색어 지우기
- 검색 결과 없음 상태
- 기본 최근 활동순
- 검색 시 제목 일치 우선
- 별도 정렬·필터 메뉴 없음

## 2. Cooking Log

- 10초 기록 버튼
- 녹음 상태
- 남은 시간
- STEP Preview 리스트
- AI 정리하기
- STEP 카드 왼쪽 스와이프 삭제
- 삭제 직후 되돌리기

핵심 기준:

- 사용자는 레시피 폼을 작성하지 않습니다.
- 기록은 음성 중심입니다.
- STEP Preview는 STT 결과를 그대로 빠르게 보여주는 중간 결과입니다.
- STEP Preview는 직접 수정하거나 재배열하지 않고 녹음 시간순으로 표시합니다.
- STEP 추가·삭제는 자동 저장합니다.
- 오류는 원인과 다시 기록할 수 있는 행동을 표시합니다.
- STT 최종 실패 시 새 STEP을 만들지 않고 기존 STEP을 유지한 채 `다시 기록하기`를 표시합니다.
- 마이크 권한이 없으면 기존 기록과 레시피 기능을 막지 않고 권한 안내만 제공합니다.

## 3. AI Review

- 첫 AI Review 맥락형 안내
- 레시피 제목
- 재료
- 조리순서
- 예상시간
- 메모
- 각 항목 수정
- 조리 단계별 독립 입력 카드
- 단계 추가·삭제·드래그 재배열
- 임시 저장
- 레시피 저장
- 저장하지 않은 변경사항 이탈 확인
- AI 정리 실패 원인
- 다시 정리하기
- 기록으로 돌아가기
- 오프라인 AI 정리 연결 필요 안내
- AI 정리 처리 중 상태와 중복 실행 방지
- AI 정리 10초 경과 장기 처리 안내
- 앱 복귀 후 같은 요청 결과 확인
- AI 정리 중 STEP Preview 잠금
- Home의 `AI 정리 중` 카드 상태
- AI 정리 완료 앱 내부 배너
- Home의 `검토 준비됨` 카드 상태
- 최종 저장 실패 시 현재 편집값 유지
- 필드 오류 또는 저장소 오류 안내
- 다시 저장
- 수량만 입력된 재료 행의 재료명 필드 오류
- 조리 단계가 모두 비어 있을 때의 필드 오류

- 재료

- 메모

- `⋯` 메뉴
  - 레시피 수정
  - 레시피 삭제

## 5. Audio Player

- 첫 핸즈프리 맥락형 안내
- 현재 단계
- 현재 단계 본문
- 이전 단계
- 재생
- 정지
- 다음 단계
- 현재 단계 다시 듣기
- 가이드 종료
- 재료 듣기
- 읽기 속도
- 핸즈프리 시작·종료
- 핸즈프리 듣는 중 상태
- 음성 명령 실패와 버튼 fallback
- 첫 핸즈프리 시작 시 권한 사용 이유
- 핸즈프리 권한 거부 시 설정으로 이동

핵심 상태:

- 진입 시 1단계 준비, 자동 재생 안 함
- 단계 재생 완료 후 다음 행동 대기
- 마지막 단계 유지
- 전화·다른 오디오·Bluetooth 중단 시 일시정지
- Audio Guide가 열려 있는 동안 화면 자동 잠금 방지
